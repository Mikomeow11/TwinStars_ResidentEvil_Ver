# TwinStars ResidentEvil Ver

这是一个基于 Qt/C++ 制作的双人横版闯关小游戏，作为高级语言程序设计大作业项目。游戏以同人向实验室逃脱为主题，玩家分别控制里昂和艾达，通过跳跃、躲避尖刺、触发机关、收集草药和寻找隐藏信物完成四关撤离。

## 主要功能

- 双人本地协作闯关：P1 与 P2 需要共同到达终点。
- 四个关卡：包含平台跳跃、尖刺、双人机关门和追逐压力。
- 剧情对白：关卡开场、关键地点、死亡、拾取道具和结尾均有对白。
- 道具与彩蛋：草药收集、小熊钥匙扣隐藏彩蛋。
- 结算系统：统计草药、小熊钥匙扣、死亡次数和隐藏成就。
- 结尾演出：galgame 风格结尾对白、结尾背景、立绘切换和黑屏淡入。
- 暂停菜单：支持继续游戏、重开本关和返回封面。
- 游戏内 HUD：右上角显示当前关卡、草药收集数和死亡次数。

## 操作方式

| 玩家 | 移动 | 跳跃 |
| --- | --- | --- |
| P1 里昂 | A / D | W |
| P2 艾达 | 左 / 右方向键 | 上方向键 |

其他操作：

- `Esc`：暂停游戏
- 暂停菜单中可选择继续游戏、重开本关或返回封面

## 运行方式

1. 使用 Qt Creator 打开项目目录。
2. 使用 CMake 配置项目。
3. 构建并运行 `TwinStars_ResidentEvil_ver`。

项目图片资源统一放在 `assets/` 目录中，并通过 `resources.qrc` 加载。
